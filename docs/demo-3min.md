## 2. 固定用例（复现用）

**创建群聊**

- 智能体：产品经理、架构师、前端工程师、后端工程师、测试工程师、Orchestrator
- 项目目录：`D:/tmp-agenthub-u13/run3`（或新的 `runN`）
- 权限：自动模式（选择 OpenCode 智能体后强制自动）

**首条需求**

```text
在项目目录创建一个极简待办清单网页（原生 HTML/CSS/JS，无第三方依赖），只拆 3 个代码任务，不要创建 PRD/文档任务：
1. index.html：标题、输入框、添加按钮、任务列表容器（前端工程师）；
2. styles.css：简洁现代的样式，桌面和移动端都可用（前端工程师）；
3. app.js：支持添加、勾选完成、删除，用 localStorage 持久化（后端工程师）。
每个任务只改自己声明的文件，不要动其他文件。产品经理只确认需求，不写文件；请产品经理先确认需求。
```

**确认口令**

1. 产品经理确认后：`确认，理解正确。请继续拆解任务。`
2. 架构师方案后：`确认执行`（必须精确，计划消息里也写了这句话）

**预期结果**

- 3 个用户任务 + 1 个系统验证任务
- 文件：`index.html`、`styles.css`、`app.js`
- 打开 `index.html`：新增、勾选、刷新持久化、删除均正常
- 聊天区系统事件合并为 ≤ 2 条通知，详情在抽屉

## 3. 不要做的事

- 不要现场跑完整链路：真实执行约 16–18 分钟，3 分钟演示只看已完成会话。
- 不要打开任务 trace 的原始 JSON 逐字段解释。

- 不要把 schema 纠偏说成失败：任务最终 completed，纠偏记录在系统事件里可查。

## 4. 应急

| 情况 | 处理 |
|---|---|
| 侧栏会话太多找不到 | 搜索 `run3`；必要时直接打开 `/chat?session=e7b5e21f-77f4-42b0-8718-22dd64080d02` |

| 生成页面 localStorage 有旧数据 | DevTools → Application → Clear site data，或换一个任务名演示 |
| 系统事件抽屉打不开 | 跳过 2:05–2:25，直接讲 3 次连续跑结果 |
| 需要展示失败/重做 | 用 `U13 敏感路径验证` 会话：任务轨迹里有「敏感路径越界」失败记录，随后安全 redo 成功；不要现场重跑 |

## 5. 已知边界（被问到再答）

- **Diff Accept/Reject**：组件已接好，但当前 Agent 输出协议没有主动发 `artifact:diff`，所以这次 golden path 没有出现 Accept/Reject 按钮。任务级 diff/回滚属于 U14。
- **Schema 纠偏**：部分 Agent 首次不输出声明字段，系统会纠偏重试；任务最终完成，记录收进系统事件抽屉。已给任务 prompt 增加产出格式提示，但未完全清零。
- **耗时**：单次 golden path 约 16–18 分钟，主要耗时在 CLI 执行和 schema 纠偏；3 分钟演示使用已完成会话。
